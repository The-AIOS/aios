# Hooks

> Scripts that run as part of vault commands OR as Claude Code event hooks. Vault-command hooks invoked from command files. Event hooks (UserPromptSubmit + statusLine) wired in `~/.claude/settings.json` per [SETUP.md §10](../SETUP.md).

## Vault-command hooks

| Hook | Used by | What it does |
|------|---------|-------------|
| `pipeline-executor.py` | `/today`, `/close-day` | Pre-loads Google Calendar, Tasks, and Slack data in one batch. Commands read the output instead of calling APIs individually. The calendar comes as **today** plus a **14-day lookahead grouped under one `**YYYY-MM-DD (Weekday)**` header per day** — fetched for every command, because it is the authoritative answer to "when is that meeting?" and a date restated in the vault is a copy. Runs via `uv run` with inline deps. |
| `buffer-status.py` | `/close-day`, `/close-session`, `/aios:housekeeping` | Reports the **observation buffer's** state as numbers: counts by class (`behavioural` / `method`), what is over cap, what states no route target, what is past the 30-day clock. Reading `session-insights.md` in full costs ~13-22k tokens, which is why its cap and clock drifted while they were enforced by impression — this costs a couple of hundred. Reports the **entries'** cost and the **whole file's** separately, and warns when the file is mostly furniture the caps do not govern (routing tombstones, front matter). **Reads only, never edits.** Exit `0` within contract · `1` action needed · `2` could not measure (an unparseable shape fails loudly rather than reporting a healthy zero). `uv run ~/aios/hooks/buffer-status.py [path] [--json]` — **through `uv`, never `python3`**: on Windows that name resolves to the Microsoft Store alias, prints an installer notice and runs nothing, so the check emits no output and reads exactly like a clean result. |
| `whoami` | CLAUDE.md § Mandatory First Action, every session start | Prints this session's identity: `CLAUDE_AGENT_NAME`, else the last `agent-name` record in its transcript (routines and bridge sessions are named without the variable); empty for a plain CLI session. One command with no `$` in it, so the startup check never triggers a permission prompt. Always exits 0. |
| `transcript-inventory.py` | `/aios:housekeeping` Bucket 36 | Sorts Claude Code's session transcripts by their own records (**named**, **unnamed**, **headless**, **temp-run**) with counts, sizes and the retention in force, and lists the **throwaway candidates** (headless or temp-folder runs older than 14 days; named and interactive sessions are never proposed). `--archive`, only after the operator's yes, writes them to a dated `.tar.gz`, verifies each at full size, then deletes; a failed archive deletes nothing. |
| `aios-health.py` | `/today`, `/close-day`, the quota watcher, its installers | **Routine health** (AI-173, contract from #171). One small file per scheduled job in `~/.aios/health/`, written at the END of a completed run with a deadline (`valid_until`), so a job that **fails** and a job that **stops running** both show up: the second because its deadline passes with nothing written. `write NAME ok|warn|fail|pending --valid-for 90m`, `report` (one line per job that needs attention, silent when all are fine), `retire NAME`. Installers register a job as `pending`, so one that never runs is overdue rather than invisible. Machine-local, never in the vault. The quota watcher is the first writer. |
| `observed-staleness.py` | `/today`, `/close-day` | The **observed-context staleness alarm**, as code. Reads every `observed/*.md` file's own `updated:` stamp and reports what crossed its threshold — **21d** for the aggregate Tier B files (`ecosystem.md`, `profile.md`), **30d** for the rest — and prints, rather than hides, the files that have **no clock at all**: `restated: true` (a spec rewritten in place) and `status: historical-snapshot` (a closed historical record with no write trigger). The alarm's threshold half was always reliable; the **exemption** half was prose, so it was re-derived by hand every morning and eventually disbelieved — nine consecutive mornings on a live vault, four of them writing *"excluded from here on"*, then a session that proposed backfilling a file frozen by design. An invisible exemption is a muted alarm, so exempt files are listed too. **Reads only, never edits.** Exit `0` nothing stale · `1` something crossed · `2` could not measure (a missing or unparseable `updated:` fails loudly instead of reporting a healthy zero). `uv run ~/aios/hooks/observed-staleness.py [dir] [--json] [--today YYYY-MM-DD]`. |
| `context-floor.py` | every session's **Session Start** (CLAUDE.md § Identity & Greeting, both spawn wrappers, `floor-at-start.py`) | Builds the **context floor in one call** and **writes it to a private file in `.aios-run/floor/` at the framework root** (gitignored, 0700, inside the session's working folder so it stays readable under `blockReadsOutsideWorkingDirectories`), printing only a short **map** (sections, sizes, the file path) — stdout is not the floor; read the file to its `=== END OF FLOOR` line (`--print` puts the whole floor on stdout for a pipe). The floor holds both `_index.md`, every heading in both folders, **the newest 5 `###` entries of every `observed/` file in full** (newest by the date each entry carries, not file position), `INTENT.md` and the ventures listing; a rule library emits its index instead, and a `restated: true` file is mapped, not read. Exists because a headings-only floor left a session knowing what *exists* and nothing the system had *learned*. The slice is **bounded**, so ten times the entries costs the same — **a bounded selector never goes stale where an unbounded volume does.** Globs both folders; no filename is hardcoded. **Refuses rather than writing a partial floor.** Exit `0` · `2` could not emit. `UV_CACHE_DIR="${TMPDIR:-/tmp}/uv-cache" uv run ~/aios/hooks/context-floor.py [path] [--recent N] [--json] [--print]`. Guard: `tests/context-floor.test.sh`. |
| `floor-at-start.py` | SessionStart (SETUP §10 Hook E) | **Delivers the floor instead of asking for it.** Runs `context-floor.py` (so the file is written) and hands a new session a **compact floor** as context: `INTENT.md` whole, the titles of the newest entries of each observed file, and the map. Unattended routines (`CLAUDE_CODE_ENTRYPOINT=sdk-*`) get `INTENT.md` alone; a resumed session nothing; `AIOS_FLOOR_AT_START=0`/`=1` opt out/in. Over 60 KB it sends the pointer only. Exits `0` and prints nothing on any failure — a context hook must never stop a session starting. Guard: `tests/floor-at-start.test.sh`. |
| `install-settings.py` | SETUP step 8 | Wires the universal hooks (A, B, D, E, F; C once a company is mounted) into `~/.claude/settings.json` **without a raw-JSON approval**: by default prints one plain line per hook and changes nothing; `--apply` merges (every key kept, an existing status line never replaced), backs the old file up, and reads its write back. Every command it writes is one SETUP §10 prints, on both platforms. Exit `0` · `1` the file is not valid JSON (untouched) · `2` the write did not verify. Guard: `tests/install-settings.test.sh`. |
| `model-switch-log.py` | PostModelSwitch (SETUP §10 Hook F); `/close-session`, `/close-day` | Appends one line per model switch to `~/.aios/model-switch.jsonl` (`at`, `session_id`, `name`, `from`, `to`, `requested`, `reason`), so a worker that finished on a model nobody chose is named instead of invisible. `--report [--since DATE] [--session ID]` prints only switches that left a session off the model it asked for, and nothing otherwise. Never blocks, exits `0`. Guard: `tests/model-switch-log.test.sh`. |
| `clip` | any session putting paste-bound text on the clipboard (CLAUDE.md § Deliverables land standalone); the spawn wrapper | Copies a file or stdin to the clipboard with a **forced UTF-8 locale** (macOS `pbcopy` falls back to Mac Roman without one, so `→`, `—` and accents arrive mangled), then **reads it back and compares content**. macOS, Windows (Git Bash → PowerShell), Linux (wl-copy / xclip / xsel). Exit `0` verified · `2` no clipboard here (give the file path instead) · `3` read-back differs (do not claim the copy). `~/aios/hooks/clip [FILE]`. Guard: `tests/clip.test.sh`. |
| `context-rungs.py` | the `right-context` skill, `/aios:housekeeping` (Bucket 31) | Measures what each rung of the **context ladder** costs *in the vault in front of it* — both `_index.md` (rung 0), every heading in both folders plus what the floor emits per observed file (rung 1, priced with `context-floor.py`'s own selection function, so a rule library costs its index), all of `declared/` (rung 2), everything (rung 3) — in words and estimated tokens, ending in a verdict. Exists so **no file hardcodes a volume**: `"read everything"` was correct when written (a fresh clone's whole context is a few thousand tokens) and silently stopped being correct as vaults grew past six figures, because nothing measured. Same rule, opposite advice, both right. **Refuses rather than reporting a partial ladder** when a folder is missing — a total built from one folder reads as SMALL, which is the answer that talks a session out of loading anything. Exit `0` measured · `2` could not measure. `uv run ~/aios/hooks/context-rungs.py [path] [--json]`. Guard: `tests/context-rungs.test.sh`. |
| `recall.py` | on demand, when a title in the floor points somewhere or a lesson you half-remember has no title to find it by | **Searches the *bodies* of `observed/` by concept** and returns `path:line :: title` plus a short excerpt. Exists because the floor names every title and prints only the newest few bodies, so an old lesson whose title does not name the concept is invisible to a session looking for the concept, and nothing says it missed. The floor stays as it is; this is the other half of index-then-open. One row per `###` entry, split by `context-floor.py`'s own function so both see the same entries; `observed/` only, globbed, never `declared/`; stdlib-only (in-memory SQLite FTS5, BM25, title weighted over body); **writes nothing**, not into the vault and not beside the hook. **Hard output cap** (`MAX_TOTAL_CHARS`, measured on the whole rendered text) that no flag can raise: `--limit` (default 5), `--excerpt` and `--max-chars` only lower or are clamped, and the output says when it trimmed. Query words are tokenized and quoted, so quotes, `AND`/`NEAR`, `*` and `-` are plain words. **Prefix + any-word by default**, decided by measurement (SQLite has no Spanish stemmer, `autoriza` must find `autorización`): `--exact` for whole words, `--all` to require every word. **Refuses rather than answering from nothing**: exit `0` matches · `1` the index was built and queried and nothing matched (it states how many sections it searched) · `2` could not run (no `observed/`, no FTS5 in this Python, no searchable word, bad flags). A file it cannot read or decode is named in the output, never dropped silently. `UV_CACHE_DIR="${TMPDIR:-/tmp}/uv-cache" uv run ~/aios/hooks/recall.py "build cache stale credentials" [--vault PATH] [--limit N] [--excerpt N] [--max-chars N] [--exact] [--all]`. Opt-in: nothing calls it. Guard: `tests/recall.test.sh`. |
| `page-fit.py` | `/weekly-learnings` (step 3b), `/learned` | Renders a report HTML in headless Chrome/Chromium and measures every `<div class="page">` against one A4 sheet (297 mm = 1123 px), naming each overflowing page and its excess in px. HTML has no page, so an overflow reads fine on screen and only shows at print time — *"fit exactly 3 pages"* had been a judgment nobody measured. Reads the DOM as it streams and kills the browser, because desktop Chrome can print the DOM and never exit. Exit `0` fits · `1` overflow or wrong `--expect` count · `2` could not measure (never reported as a fit). `uv run ~/aios/hooks/page-fit.py [--expect N] <report.html>`. Guard: `tests/page-fit.test.sh`. |
| `context-load-audit.py` | `/aios:housekeeping` (Bucket 30) | Reports spawned workers that did real work having loaded **no** operator context, read from the on-disk transcripts. Counts `tool_use` records only (a `tool_result` echo is not a read), resolves `cd`-then-bare-filename reads via the session's working directory, and separates floor-depth reads from full reads. **Unaffected by compaction** — the transcript on disk is append-only. **Aborts rather than reporting** when no primary session validates it. Primaries are the names in `USER.md`'s `## Identity` table (plus `--primary NAME`), never names written in the hook: without a control, a fleet that read nothing and a detector that matches nothing look identical, and the first version did exactly that (full-path matching missed every worker that `cd`s into the context folder, reporting workers at zero that had read the whole floor). `uv run ~/aios/hooks/context-load-audit.py`. **Also reports FIT, not only volume:** it names any worker that took an outward-facing action (wrote to `03 - export/`, sent mail or a message, created a doc) before reading any `declared/` file, over the whole transcript rather than the loading window — the failure that does not announce itself, since the output reads fluent either way. Guard: `tests/context-load-audit.test.sh`. |
| `unfinished-work.sh` | `/close-day`, `/today` | Lists notes whose frontmatter `status:` says the work is still open (proposal, draft, in progress…) while no open `- [ ]` task in a project note or the newest daily note links to them. `/today` reads tasks, not documents, so such a note has no exit. Skips `logs/`, `context/` and `projects/`. `AIOS_OPEN_STATUSES` overrides the status list for an operator's own vocabulary. **Reads only.** Always exits `0`; prints `unfinished-work: none` when clean. Guard: `tests/unfinished-work.test.sh`. |
| `freshness-probe.sh` | `/today`, `/close-day` | The framework (`.aios-update`) and per-company freshness checks. Keeps git's error output so a **refused credential** (`Permission denied` · `Repository not found` · `could not read Username` · `Authentication failed`) reports `access-denied`, never `unreachable` — the inline version discarded stderr and rendered a removed SSH key as "offline — fine". Modes: `--aios-update` · `--companies` · `--classify`. Always exits 0. Guard: `tests/freshness-probe.test.sh`. |
| `openrouter.py` | any command / skill / routine, and `/aios:housekeeping` Bucket 27 | Calls a **non-Claude** model as a tool — text in, text out, stdlib-only (no `pip install`). Two uses, one file: a cheap text lane, and an **independent judge** (a model cannot dock points for a bias it shares). Resolves `OPENROUTER_API_KEY` → OpenRouter, else `GEMINI_API_KEY` → Gemini direct, else refuses while naming both paths — **never a silent no-op**, because a scorer that returns nothing reads exactly like a scorer that found nothing wrong. **Opt-in and silent until configured: it is the one AIOS component that sends your content off-machine to a third party.** No MCP tools, no vault writes. `python3 ~/aios/hooks/openrouter.py --check` reports what is wired without making a call. Boundaries: [`MODEL-ROUTING.md`](../MODEL-ROUTING.md). |
| `markitdown-convert.py` | `/ingest` + standalone | Converts any file (PDF, Word, Excel, PowerPoint, images, audio, YouTube, EPUB, HTML, CSV, JSON, XML, ZIP) → clean markdown. Wraps Microsoft's MarkItDown library. **The universal, cross-platform default converter** — the two media hooks below are macOS *enhancements*, not replacements. Standalone: `python3 ~/aios/hooks/markitdown-convert.py <file>`. |
| `transcribe.py` *(macOS)* | `/ingest` (long-form audio/video) + standalone | Local long-form transcription (`ffmpeg → mlx-whisper large-v3-turbo`) — the macOS upgrade for MarkItDown's one audio weakness (its Web-Speech path fails past a sentence). Arbitrary length, on-device, no third party. **macOS/Apple-Silicon only** (mlx); MarkItDown remains the non-Mac path. Optional deps: `python3 -m venv hooks/.venv && hooks/.venv/bin/pip install mlx-whisper`. Standalone: `python3 ~/aios/hooks/transcribe.py <file-or-URL> [out.txt]`. |
| `motion-render.py` | the `motion-lab` skill | Renders code-drawn motion **frame by frame**: opens one HTML file in headless Chromium, freezes it at each `t = i/fps` (`window.renderAt(t)` plus every CSS animation), saves PNGs; then `sheet` (contact sheet), `onion`, `speed` (from `window.__probe(t)`), `export` (H.264 MP4, a GIF whose delays do not drift). You own the source, so render the frames you want — never sample your own frames back out of an MP4. Python Playwright + Pillow + ffmpeg; each subcommand says which is missing. Guard: `tests/motion-lab.test.sh`. |
| `motion-check.py` | the `motion-lab` skill | **Measures** a motion piece instead of watching it: `contract` (static lint: no clock, timers, unseeded random, network; pinned libraries; `renderAt`), `determinism` (a frame renders identically twice), `seam` (last frame → first), `pops` (a frame that jumps past its neighbours, named), `assert` (the brief's numbers against `__probe`), `audio` (LUFS, true peak, energy under 60 Hz, each hit one frame after its picture). PASS/FAIL with numbers; a check that could not run exits `2`, never a pass. Guard: `tests/motion-lab.test.sh`. |
| `video-watch.py` + `ocr-image.swift` *(macOS)* | `/ingest` (screen-comprehension, opt-in) + standalone | Reads the video **screen** (slides · code · diagrams · on-screen text) — the capability MarkItDown lacks entirely (it discards every frame). Pipeline: transcript-first → `ffmpeg` scene-keyframes → pHash dedup → per-frame reader (`ocr` verbatim via Apple Vision `ocr-image.swift` · `vlm` structure via `claude -p` · `both`) → merged timeline. Fortress-clean (on-device OCR + subscription-auth VLM, no API key). **Opt-in** ("read the slides / code on screen"). OCR reader is macOS-only (Apple Vision); the `vlm` reader is cross-platform (`--reader vlm` off-Mac). Compose with `transcribe.py --transcript` to skip a second whisper model. Guide: `hooks/video-watch-guide.md`. |
| `claude-identity/` | launchd (macOS) · systemd user timer (Linux) · Task Scheduler (Windows) + statusLine | Multi-account quota autopilot. Off with `~/.claude/rc-reconnect.disabled`. See `claude-identity/README.md`. macOS-only; ≥ 2 Anthropic accounts required. |

## Claude Code event hooks

| Hook | Event | What it does |
|------|-------|-------------|
| `inject-datetime.sh` (`.ps1`) | `UserPromptSubmit` | Injects current system date/time/timezone into Claude's context before each prompt. Eliminates the "Claude infers time from conversational context instead of checking system clock" failure mode. See `antifragile.md` 2026-05-18 entry. Cross-platform: `.sh` for macOS/Linux, `.ps1` for Windows. |
| `claude-identity/claude-identity.sh cache \| context-monitor.py` | `statusLine` | Writes rate-limit cache on every Claude turn (feeds the autopilot's fast-path quota detector) + powers the context-monitor status display. Wired in `~/.claude/settings.json` `statusLine.command`. |
| `guard-venture-mount.py` | `PreToolUse` (Edit/Write/MultiEdit/NotebookEdit) | Blocks direct edits to company-context **mounts** — `context/ventures/{v}/` files carrying a `.{v}-sync` marker are synced copies of a `{v}-context` source repo; editing them is reverted on the next `/aios:company --sync`. Points at the source repo instead. The framework's first PreToolUse hook. **Fail-open** (never bricks editing), **deterministic** (~nil false-positives), escape hatch `AIOS_ALLOW_MOUNT_EDIT=1`; the rsync sync path is exempt (Bash, not Edit/Write). Wire per SETUP §10 Hook C. Born from `antifragile.md` #81. |
| `bus_log.py` | `PreToolUse` (`Write\|Edit`, `--hook`) · inbox sweep (`--sweep`) | Fingerprints every spawn-inbox request as it is written, so `provenance.py` can tell a prompt the bus typed from one the operator typed. Never blocks. SETUP §10 Hook D. |
| `provenance.py` | `UserPromptSubmit` (`--prompt`) · `PostToolUse` on reading tools (`--tool`) | Adds one line of context marking text that is not the operator's: tool results from email, chat, docs, web and Forum, and prompts the spawn inbox typed. By structure, never wording; never blocks. SETUP §10 Hook D. |
| `issue-scrub.py` | `aios-feedback` agent | Strips the vault out of an issue draft before it leaves the machine: home paths → `~`, vault paths/wikilinks/verbatim context quotes → placeholders, names loaded from USER.md + context/ + projects → roles, plus emails, Slack/Drive ids, phones and token shapes. Prints a redaction count including `names loaded` (a scrub that loaded zero names says so). Exit `0` scrubbed · `1` `--check` found something · `2` bad input. `UV_CACHE_DIR="${TMPDIR:-/tmp}/uv-cache" uv run ~/aios/hooks/issue-scrub.py [file] [--out F] [--check] [--term NAME]`. Guard: `tests/issue-scrub.test.sh`. |

## Operator extensions

- `custom/` — your own hooks (survive `/aios:update`). Documented in `custom/_index.md` with the registry table format.

**Wiring:** event hooks are wired in `.claude/settings.json` (project-level) or `~/.claude/settings.json` (user-level). The vault ships a project-level `.claude/settings.json` that wires `inject-datetime.sh` to `UserPromptSubmit`. On Windows, use `powershell -NoProfile -ExecutionPolicy Bypass -File` (not `pwsh`, which a stock install lacks) and `python` (not `python3`, the Store placeholder) — SETUP §10 → *On Windows* has the exact block. **`PreToolUse` hooks** (e.g. `guard-venture-mount.py`) wire the same way with a `matcher` — see SETUP §10 Hook C.

## Adding a hook

**Vault-command hooks** (referenced by command files):
1. Create the script in this folder
2. Document it in this index
3. Update SETUP.md to install it to `~/.claude/hooks/`
4. Reference it from the command that needs it

**Claude Code event hooks** (run automatically on Claude Code events):
1. Create the script in this folder (executable for `.sh`; ASCII-only for `.ps1` to survive Windows PowerShell 5.1)
2. Document it in this index
3. Wire it in `.claude/settings.json` under `hooks.{EventName}` — see existing examples
4. Restart Claude Code session to pick up the new hook
