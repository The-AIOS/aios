Componentes de Arquitectura

Core
Agente SSI Multi-Tenant
NestJS · @extrimian/agent
Servicio central de identidad. Emisión, verificación y revocación de credenciales verificables W3C. Un agente por tenant (gobierno/institución).
Identidad
DID + Resolución
did:quarkid · DID Resolver
Identificadores descentralizados. Resolución de DIDs, registro en blockchain, múltiples métodos soportados.
Credenciales
VC Core + Verificador
@extrimian/vc-core · vc-verifier
Emisión y verificación de credenciales W3C. Presentaciones verificables via protocolo WACI (DIDComm).
Seguridad
Key Management
Google Cloud KMS · Secret Manager
Gestión de claves criptográficas en hardware seguro de Google. Secretos y credenciales nunca en código.
Base de datos
Almacenamiento
MongoDB Atlas
Base de datos NoSQL escalable. Almacenamiento de agentes, credenciales, presentaciones y configuraciones por tenant.
AI-Ready
MCP Server
@modelcontextprotocol/sdk
Servidor MCP que permite a agentes AI (Claude) emitir, verificar y gestionar credenciales via lenguaje natural.

Flujo de Credenciales

1
Emisión
El gobierno emite una credencial verificable al ciudadano via WACI.
→
2
Almacenamiento
El ciudadano guarda la credencial en su SovraWallet. Él controla sus datos.
→
3
Verificación
Cualquier entidad puede verificar la credencial sin contactar al emisor.

Seguridad y estándares

Criptografía
Google Cloud KMS para gestión de claves. Firmas BBS+ para privacidad selectiva. Secretos en Secret Manager, nunca en código.
Multi-tenancy
Un agente SSI por tenant (gobierno/institución). Aislamiento completo de datos, claves y configuraciones entre tenants.
Estándares W3C
Verifiable Credentials, Decentralized Identifiers, DIDComm/WACI. Interoperabilidad con cualquier sistema compatible.
Ambientes
Dev, Sandbox, Staging, Producción. Cada ambiente con sus propias claves, bases de datos y configuración aislada.
