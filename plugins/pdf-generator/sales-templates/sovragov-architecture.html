Seguridad y protección de datos

Encriptación
Datos en tránsito: HTTPS/SSL. Datos en reposo: SHA-512 + PyCrypto. Contraseñas encriptadas a 512 bits.
Control de accesos
Autenticación federada (OAuth2, OpenID Connect), JWT con revocación, Firestore Security Rules, App Check.
Protección activa
Detección de bots/flooders, protección CSRF, certificación SSL, copias de seguridad periódicas automáticas.
Respuesta a incidentes
Logs detallados via Cloud Logging + Monitoring. Protocolos de manejo y reporte de incidentes de seguridad.

Propiedad de los datos

  • Los datos son siempre propiedad del gobierno — Sovra opera como proveedor SaaS
  • El gobierno tiene acceso a respaldos fidedignos de la base de datos en producción
  • En caso de terminar el contrato, el gobierno dispone de toda la información del ciudadano
  • Políticas de minimización, exactitud, limitación de propósito y almacenamiento
