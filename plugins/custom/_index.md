# Custom Plugins

> Your custom Claude Code plugins. These survive `/aios:update` — bundled plugins in the parent `plugins/` folder get replaced, but `custom/` is yours.

Add a folder per plugin following [Claude Code's plugin spec](https://docs.claude.com/en/docs/claude-code/plugins). Document each in the registry below.
