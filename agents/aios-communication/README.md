# aios-communication

> Content, decks, emails, meetings, design systems. The "make every external surface tight" bundle.

The largest bundle — covers everything that ships externally on your behalf or in your voice.

## Agents

| Agent | What it does |
|---|---|
| [[content-writer]] | Draft posts for LinkedIn, Twitter/X, Substack in your voice — pulls from observed patterns, voice signals, recent vault context |
| [[content-scheduler]] | Plan and queue content calendar from vault insights. Runs Monday — surfaces themes from the week's signals |
| [[email-drafter]] | Draft professional emails matching your voice + the recipient's context |
| [[deck-builder]] | Build presentations end-to-end via the AIOS 6-phase process: design discovery → outline → images → live-MCP Slides → polish → validation |
| [[meeting-prepper]] | Prepare context-rich briefings for upcoming meetings — disambiguation, demo-vs-discovery flow, materials checklist |
| [[report-drafter]] | Draft status reports and board updates from vault activity — pulls from project notes + daily notes |
| [[design-md-author]] | Author `design.md` files per Google's spec — interview-driven, validates via `npx @google/design.md lint`, optional Stitch upload |

## When to install

- You publish content (any cadence)
- You give presentations, pitch decks, or workshops
- You email clients, partners, investors regularly
- You want consistent voice across surfaces
- You design (or have a brand that needs a design system)

## Dependencies

- **Gmail MCP** — drafts
- **Google Workspace MCP** — Docs, Slides, Sheets
- **Obsidian MCP** — voice + content + project context
- **Optional: Stitch MCP** — for design.md → UI generation pipeline

See [[../_index|top-level agents registry]] for the full agent vocabulary.
