# aios/sales

> Lead generation, proposals, CRM, and brand monitoring.

Install this bundle if you do outbound sales, write client proposals, manage a deal pipeline, or track brand mentions.

## Agents

| Agent | What it does |
|---|---|
| [[sales-lead-hunter]] | Explore inbound/outbound leads, qualify with a 4-dimension scoring framework, draft personalized outreach emails as Gmail drafts |
| [[sales-proposal-writer]] | Draft tailored consulting/training proposals from project notes + the user's consulting catalog — Google Docs or HTML-to-PDF outputs |
| [[sales-crm-updater]] | Sync deal updates to Monday/CRM from meeting notes, daily plans, or Slack threads |
| [[brand-monitor]] | Weekly Monday scan — track mentions, competitor moves, industry news; surface in a structured digest |

## When to install

- You handle inbound leads and want them qualified before you touch them
- You write proposals frequently and want voice/format consistency
- Your CRM (Monday, HubSpot, Pipedrive) has deals that need ongoing updates
- You want a weekly competitor + brand pulse without doing the scanning yourself

## Dependencies

- **Gmail MCP** — for outreach drafts (sales-lead-hunter, email-drafter handoffs)
- **Google Workspace MCP** — for proposal documents
- **Monday MCP** (or your CRM's MCP) — for sales-crm-updater

See [[../_index|top-level agents registry]] for the full agent vocabulary.
